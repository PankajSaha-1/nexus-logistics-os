# Nexus Logistics OS

A modern and minimalistic logistics operations platform built with React, Vite, and Tailwind CSS.

Nexus Logistics OS is designed to help logistics teams manage shipments, drivers, vehicles, dispatch operations, and AI-powered ETA insights from a centralized dashboard.

## 🚀 Features

- 📊 Operations Dashboard
- 📦 Shipment Management
- 🚚 Fleet Management
- 👨‍✈️ Driver Management
- 🔄 Dispatch Board
- 🤖 AI ETA Insights
- 🔐 Login Interface
- ⚙️ Settings & Demo Controls
- 🔎 Shipment Search and Filtering
- 📈 Operational Analytics
- 🔔 Notification and Toast System
- 📱 Responsive Design
